## Формат визуальной разметки

Заполненную копию `annotations.blank.json` сохраняют под новым именем.
Каждое `unit` охватывает один стол и заранее выбранное окно кадров.
`coverage_complete=true` и `VISUALLY_REVIEWED` требуют имени проверяющего и
времени проверки; без них метрики не считаются. В `rows` создают отдельный
`row_id` для каждой видимой физической строки, один или несколько якорей
`{"evidence_id": "...", "bbox": [x1,y1,x2,y2]}` в локальных пикселях
замороженного чат-PNG и `visual_text` вида `{"state":"KNOWN","value":"..."}`.
Нечитаемый текст получает `UNKNOWN` или `AMBIGUOUS` с `value:null`.

В `messages` создают отдельный `message_id`, `order`, упорядоченные `row_ids`,
`completeness` (`COMPLETE`, `PARTIAL`, `UNKNOWN`), хотя бы один сценарий из
`parser_core/annotation.py:SCENARIOS` и поля `actor`, `action`, `amount`,
`role`, `cards`. У каждого поля `state` — `KNOWN`, `NONE`, `UNKNOWN`,
`AMBIGUOUS`; только у `KNOWN` есть значение. Для `cards` значение — список.
`NONE` означает визуально доказанное отсутствие поля, `UNKNOWN` — недостаток
доказательства. Суммы хранятся строкой в строгом согласованном представлении
(например `6000`); аудитор ничего не исправляет и не нормализует в эталоне.
Обрезанное начало/конец помечается `PARTIAL`, и нельзя заполнять неизвестные
поля по OCR. Проверяющий должен просмотреть полный чат и соседние кадры,
чтобы `coverage_complete` имело смысл; программа может проверить структуру,
хеши и владение строками, но не факт честного визуального просмотра.

## Запуск аудита и сравнения

```powershell
python scripts/evaluate_visual_corpus.py annotation/smoke12_candidate_f00000_5f_v1 `
  --output annotation/reports/smoke12_candidate_audit_next

python scripts/evaluate_visual_corpus.py annotation/dev_frozen_corpus_v1_20260928 `
  --run runs/smoke10_f1800_retry_v1_ru_v4 `
  --run runs/smoke11_gameplay_f1425_1f_retry_v1_ru_v4 `
  --run runs/smoke11_nine_table_5f_roi_cal_retry_v1_ru_v4 `
  --assembler message_assembly_v5 --normalizer candidate_ru_v4 `
  --output annotation/reports/dev_comparison_next
```

Скрипт только читает SQLite в режиме `mode=ro`. Версии assembler и normalizer
задаются явно. Сравнивает геометрию строки по общему исходному chat-PNG,
сохраняет отдельные одинаковые тексты, не сопоставляет действия по OCR или
номеру строки. Результаты: `audit.json`, `predictions.json`, `comparison.json`.
Считает exact actor/action/amount/role/cards, exact event, false acceptance,
unresolved, пропуски, лишние результаты, разделения/склейки границ и пары
неверного порядка. Каждая доля содержит числитель и знаменатель, есть
сегменты сценариев и `NOT_TESTED`. `CANDIDATE` не является принятым событием;
по умолчанию accepted только `VERIFIED`.

На пустой разметке оба frozen-аудита прошли по структуре и SHA; результат
`NOT_MEASURED`, проверенных сообщений 0. DEV-адаптер выбрал ровно 386 текущих
событий (127+128+131) и 472 фрагмента без пустых ссылок на PNG;
264 `CANDIDATE`, 122 `UNRESOLVED`. Это проверка связей журнала, **не** оценка
точности. Тесты: `python -m pytest -q` → 44 passed.

До приёмки Stage 1 нужны независимые размеченные ≥300 полных сообщений,
≥30 трудных переходов и ≥10 полностью наблюдаемых рук. Текущий оценщик
измеряет события; переходы, entity-boxes, полные руки, HH и скорость пока
не оценивает. Smoke12 5 кадров — лишь первый сырой контроль, не весь
тестовый корпус. Никаких сертифицированных HH не появилось.

## Очередь слепой визуальной проверки

`annotation/smoke12_changed_chat_review_v2_20260928/changed_chat_frames.csv`
содержит исходные PNG чата и стола, evidence ID, PTS и SHA для первого кадра
и каждого последующего изменения **байтов чат-PNG** в пределах окна стола.
Из 4860 сохранённых чат-кадров выбраны 3349 (27 окон).
`visual_review_status=UNREVIEWED`; полей текста/сообщений здесь нет — их
размечают отдельно в копии `annotations.blank.json` по протоколу.
Это очередь для человека, а не эталон и не число новых сообщений: изменение
изображения может быть вызвано интерфейсом, а одинаковые кадры с шагом 10
не доказывают отсутствия событий между ними. Краткий отчёт:
`annotation/smoke12_changed_chat_review_v2_20260928/queue_summary.json`.
