# Очередь визуальной проверки, smoke11

`annotation/dev_smoke11_queue_20260927` содержит неизменяемый манифест выбора и локальные PNG:

| Материал | Число | Что требует проверки |
|---|---:|---|
| Сообщения-кандидаты | 300, все 35 типов исходного каталога | Текст, границы, semantic type и смысл сумм по изображению |
| Трудные переходы чата | 30 | Порядок и идентичность строк до/после скролла |
| Окна между соседними `HAND_HEADER` | 12 | Наличие полного начала/конца и всех событий руки |

Среди сообщений 62 имеют несколько исходных физических кропов и 48 видны уже в первом кадре стола. Среди переходов: 11 `UNRESOLVED_ALIGNMENT`, 11 `PARTIAL_TOP_UNRESOLVED`, 8 `UNRESOLVED_INTERNAL`. Для каждого перехода есть строковый кроп и контекст до/после; текущий кадр взят из сохранённых PNG в 19 случаях и заново декодирован из отдельного видео стола в 11 случаях. Последний вариант явно помечен как производный от видео с потерями кодека.

В исходном CSV `crop_sha256` означает SHA-256 декодированных BGR-пикселей. Скрипт проверил его отдельно и дополнительно записал SHA-256 байтов каждого PNG. Это разные хеши. Каталоги и старые файлы не изменялись.

Для 12 начальных кадров окон рук проверена привязка кадров отдельных видео столов к сохранённым PNG: среднее абсолютное отклонение пикселя составило 2.85–4.34 из 255. Это подтверждает положение кадров с учётом сжатия видео; полноту рук не доказывает.

Файлы `messages_to_review.csv`, `transitions_to_review.csv`, `hands_to_review.csv` имеют пустые поля для проверенной разметки. Они **не заполнены автоматически** из OCR-подсказок. `manifest.json` хранит исходные пути, хеши, происхождение кадра и статус `UNREVIEWED`. Эта очередь взята из smoke11, который уже использовался при составлении каталогов, поэтому является **материалом разработки, не независимым финальным тестом**. Ни одно из 12 окон пока не доказано полной рукой.

Повторное построение:

```powershell
python scripts/prepare_annotation_queue.py
```
