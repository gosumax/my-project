10. START_STACK
==================================================

Для каждой полной руки хочу START_STACK игроков.

PokerDom displayed stack уже после списания ante/blinds.

Поэтому если первое чистое наблюдение показывает X,
и до него доказаны forced debits:

START_STACK =
displayed stack
+ proven ANTE
+ proven SB/BB
+ другие точно доказанные списания до snapshot

Добровольные действия добавлять обратно только если:
- actor доказан;
- amount доказан;
- порядок доказан.

Если нет однозначности:
UNKNOWN.

Статусы:
- PROVEN
- SUPPORTED
- UNKNOWN
- CONFLICT

Никаких догадок.
