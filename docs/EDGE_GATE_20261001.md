## BOUNDARY RULES

Каждый table/session независим, caller order сохраняется. Отсутствующие identity/order поля, duplicate row ID/physical position, обратный порядок дают UNRESOLVED_EDGE.

Начало: source-linked explicit NEW_HAND с безопасной identity/reading metadata; либо последовательные `[ANTE*] SMALL_BLIND BIG_BLIND DEAL` в одной epoch с прочитанными actor и positive amount. Одиночные SB/BB, номер/header, empty board, pot/stack reset, ROI change или time gap не создают начало. Header непосредственно перед explicit start включается в ту же руку. Pattern первого forced-bet блока не создаёт второе начало после explicit start, включая служебные TABLE_INFO.

До первого начала — PARTIAL_START. Следующее подтверждённое начало закрывает предыдущую руку независимо от WIN/SHOW. Последняя рука — KEEP только при source-linked positive WIN payout с безопасным последующим хвостом или VERIFIED/CONFIRMED/CERTIFIED HAND_END; иначе PARTIAL_END. Обычные SHOW или FOLD сами по себе недостаточны: надёжной полной participant roster для all-but-one fold в текущем evidence нет. Тест fold end использует folds + payout и не требует showdown.

Противоречивые/повторные номера между окнами, повторные/rejected NEW_HAND внутри окна и epoch discontinuity дают UNRESOLVED_EDGE. Эти признаки не восстанавливают partial руки и не создают новые границы. Неизвестный хвост после выплаты не доказывает окончание.
