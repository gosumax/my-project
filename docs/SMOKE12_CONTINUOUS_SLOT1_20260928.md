# Smoke12: непрерывное окно одного стола для визуальной разметки

## Выбор до просмотра результатов

`annotation/smoke12_continuous_slot1_plan_v1_20260928.json` задаёт первый
минутный интервал Smoke12, слот 01, кадры 0–1799 с шагом 1. Хеш исходного
видео указан в плане. Выбор не использовал OCR или метрики событий.

## Сохранённые доказательства

- Сырой захват: `runs/smoke12_raw_continuous_slot1_f0_1799_v1`.
  Один декодер сохранил 1800 последовательных кадров, 1800 PNG чата и 1800
  PNG стола. PTS строго возрастают от `0/15360` до `921088/15360`; источник
  помечен `PARTIAL`, потому что выбран только интервал видео.
- В сыром журнале нет OCR, строк, сообщений, событий, рук, экспортов и GAP.
  Слот имеет `identity_status=UNRESOLVED`; смена реального стола внутри окна
  ещё не проверена визуально.
- Замороженная копия: `annotation/smoke12_continuous_slot1_candidate_v1_20260928`.
  3600 PNG сверены по SHA-256. Хеш манифеста:
  `cc3eaf9e889d22fb7c54fd43c87ea6fbaa0bbf6e26474b9207738b0a5d760f3b`.
  Пустой шаблон разметки не содержит ответов OCR.
- Слепой просмотрщик и редактор черновика:
  `annotation/smoke12_continuous_slot1_review_v4_20260928/viewer.html`.
  Он показывает каждый кадр и пару чат/стол, PTS, ID исходного PNG и
  локальные координаты выделенной мышью рамки. Стрелки листают по одному
  кадру; кнопки ±10 ускоряют обзор. Проверяющий добавляет видимые строки,
  связывает их в сообщения и скачивает JSON-черновик. Его можно загрузить
  обратно для продолжения. Черновик всегда `UNREVIEWED`: только после полного
  визуального обзора и отдельной проверки по `docs/ANNOTATION_PROTOCOL.md`
  можно заверить покрытие, проверяющего и время. Никакие поля не заполняются
  из OCR; поля сообщения по умолчанию `UNKNOWN`.
  Верхнюю обрезанную строку кадра, исключённую политикой
  `FIRST_VISIBLE_ROW_EXCLUDED`, не нужно добавлять как полное сообщение:
  её пиксели сохранены в исходном PNG.
- Очередь `annotation/smoke12_continuous_slot1_review_queue_v2_20260928`
  отметила 451 кадр из 1800: первый и каждый кадр, где байты PNG чата
  отличаются от предыдущего. Это список для просмотра, **не** 451 новое
  сообщение. Изменения изображения бывают без изменения читаемого текста;
  все 1800 кадров остаются доступны в просмотрщике.

Аудит в `annotation/reports/smoke12_continuous_slot1_audit_v1_20260928`:
`valid=true`, `quality_status=NOT_MEASURED`, `independent_test=false`,
0 проверенных сообщений. Это полное по кадрам окно одного слота, но
независимость игровой сессии Smoke12 ещё не доказана, текст и границы
сообщений не размечены, полные руки не проверены. Качество парсера и приёмка
этапа 1 по этому окну пока не измерялись.

Команды воспроизведения в **новые каталоги**:

```powershell
python scripts/capture_predeclared_windows.py `
  annotation/smoke12_continuous_slot1_plan_v1_20260928.json `
  --output runs/smoke12_raw_continuous_slot1_next
python scripts/freeze_visual_corpus.py `
  annotation/freeze_smoke12_continuous_slot1_plan_v1_20260928.json `
  --output annotation/smoke12_continuous_slot1_candidate_next
python scripts/build_visual_review_viewer.py `
  annotation/smoke12_continuous_slot1_candidate_v1_20260928 `
  --output annotation/smoke12_continuous_slot1_review_next/viewer.html
```

При повторной заморозке план нужно указать на каталог нового сырого захвата.

После скачивания черновика его структуру и хеши можно проверить без метрик:

```powershell
python scripts/evaluate_visual_corpus.py `
  annotation/smoke12_continuous_slot1_candidate_v1_20260928 `
  --annotations 'путь_к_скачанному_черновику.json' `
  --output annotation/reports/smoke12_draft_audit_next
```

При `UNREVIEWED` качество останется `NOT_MEASURED`. Полная визуальная проверка
покрытия нужна до оценки точности.

## Дополнение: пользователь подтвердил отдельную сессию

Пользователь подтвердил, что Smoke12 — новая игровая сессия без пересечения
со Smoke01–11 и их копиями. Заявление, время его фиксации, SHA видео и
локальная проверка 33 журналов записаны в
`annotation/smoke12_session_independence_20260928.json`. Во всех трёх
журналах этого источника OCR, строки, события, руки и экспорты равны нулю.
Ранее кадры Smoke12 использовались только для проверки инструмента просмотра;
подбор правил или модели парсера по Smoke12 не проводился. Использование
внешних копий отдельно не аудировалось.

Старый кандидат оставлен неизменным. Новая заморозка
`annotation/smoke12_continuous_slot1_test_v1_20260928` содержит те же 1800
кадров и 3600 PNG с `split=test`, `independent_test=true` и отдельным
манифестом SHA-256
`418a740f8e7fb0cf130666b7e4c2676aac05189856e0418ac612f7b644dc86ac`.
План заморозки с хешем заявления:
`annotation/freeze_smoke12_continuous_slot1_test_plan_v1_20260928.json`.

Для этой версии использовать просмотрщик
`annotation/smoke12_continuous_slot1_test_review_v3_20260928/viewer.html`
и очередь
`annotation/smoke12_continuous_slot1_test_queue_v1_20260928/changed_chat_frames.csv`.
Очередь содержит 451 изменившийся PNG из 1800 кадров, а не 451 доказанное
сообщение. Аудит тестового корпуса находится в
`annotation/reports/smoke12_continuous_slot1_test_audit_v1_20260928`:
`valid=true`, `independent_test=true`, `quality_status=NOT_MEASURED`,
0 размеченных сообщений. До визуальной разметки это тестовый **источник**,
а не измеренная точность парсера и не приёмка этапа 1.

В просмотрщике v2 и новее рядом со строкой есть «Править текст». Он исправляет
текст черновика даже после сборки сообщения, сохраняя ID строки и связь
с сообщением. В v3 у готового сообщения есть «Править сценарий» — изменение
сохраняет ID, строки и порядок сообщения. Для перехода из старой версии
сначала скачать черновик JSON, затем открыть v3 и загрузить этот файл;
обновление старой страницы теряет несохранённую разметку.
